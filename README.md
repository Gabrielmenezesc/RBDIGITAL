# RB Digital — Rede Brasília Digital

Site institucional premium, tecnológico e cinematográfico da **RB Digital** (Rede Brasília Digital), a frente digital e criativa da empresa **Rede Brasilia News LTDA**.

## Identidade Visual & Conceito
- **Paleta de Cores:** Azul profundo (`#071A3A`), Azul tecnológico (`#0B3D91`), Prata metálico (`#C8CDD5`), Cinza metálico (`#6F7785`), Dourado (`#C9A227`), Branco (`#FFFFFF`), Preto (`#05070B`).
- **Conceito:** Sofisticação, tecnologia, autoridade institucional, linhas arquitetônicas inspiradas em Brasília e Goiás.

## Tecnologias
- **Framework:** Next.js 16 (App Router, Static Export)
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS 4
- **Animações:** Framer Motion
- **Mapas:** React Leaflet / Leaflet

## Desenvolvimento Local
```bash
npm run dev
```

## Build de Produção
```bash
npm run build
```
